# 智能文档清理器 - 使用文档

对 [yangbin09/smart-file-cleaner](https://github.com/yangbin09/smart-file-cleaner) 的深度改造版：
新增「文件名日期判定」「回收站+备份双保险」「桌面 GUI」「定时自动清理」「报告留存」「托盘后台运行」。
**删除的文件先进回收站**，误删可恢复。

## 1. 安装与启动

### 方式一：安装包（推荐）

运行 `setup\SmartFileCleaner_Setup_1.0.0.exe`，安装到 `%ProgramFiles%\SmartFileCleaner`。
安装时可勾选「开机自启（后台托盘运行）」。

### 方式二：绿色版

直接运行 `dist\SmartFileCleaner\SmartFileCleaner.exe`（无需 Python 环境）。

### 方式三：源码运行（开发者）

```bash
pip install -r requirements.txt
pip install pystray pillow   # 托盘可选，缺失自动降级为仅窗口
python main.py
```

### 启动模式

| 命令 | 说明 |
|------|------|
| `SmartFileCleaner.exe`（无参数） | 打开桌面 GUI（默认） |
| `SmartFileCleaner.exe --tray` | 后台托盘模式，无窗口（开机自启用） |
| `SmartFileCleaner.exe --auto` | 无人值守自动清理（供定时调度调用，不看界面） |
| `SmartFileCleaner.exe --preview` | 仅扫描预览，不删除任何文件 |

## 2. GUI 使用

界面从上到下依次为：

1. **目标目录**：添加/移除要清理的目录（可多个）
2. **过期规则**：过期天数（默认 30 天）；「优先用文件名中的日期判定」开关
3. **清理文件格式**：文档 / 图片 / 临时 三类勾选，或填自定义扩展名（逗号分隔，如 `.zip, .rar`）
4. **删除安全**：移入回收站、删除前先备份到 `backups\`
5. **定时与自启**：
   - 勾选「每天定时自动清理」+ 填时间（HH:MM），程序内置调度，到点自动执行
   - 勾选「开机自启」→ 写注册表 Run 键，开机后以 `--tray` 后台运行
6. **操作按钮**：保存设置 / 立即预览 / 立即清理 / 打开配置目录
7. **清理报告**：左侧列 `reports\` 下的历史报告，选中点「查看选中」看详情；右侧为实时执行日志

> 任何修改点「保存设置」即写入配置，定时/自启**即时生效**，无需重启。

## 3. 定时清理说明

- **内置调度**（推荐）：GUI 里勾选「每天定时自动清理」即可，改时间即时生效；程序在托盘/后台运行时同样生效
- **系统计划任务**（备选）：管理员运行 `注册定时清理任务.bat` 注册每日 02:00 任务（调用 `--auto`）

## 4. 配置文件（可选手工编辑）

安装版位置：`%ProgramFiles%\SmartFileCleaner\config\operation-config.json`（源码版：`src\config\`）

```json
{
  "processing_config": {
    "target_directories": ["C:/Users/YOURNAME/Downloads"],
    "max_age_days": 30,
    "use_filename_date": true,
    "target_extensions": [],
    "safety_settings": {
      "create_backup": true,
      "backup_dir": "backups",
      "use_recycle_bin": true,
      "require_confirmation": false
    }
  },
  "report_settings": { "generate_report": true, "output_dir": "reports" },
  "auto_clean": { "enabled": true, "time": "02:00", "start_with_windows": true }
}
```

| 配置项 | 说明 |
|--------|------|
| `target_directories` | 清理目录列表，可多个 |
| `max_age_days` | 过期天数阈值 |
| `use_filename_date` | 优先用文件名日期判定，解析失败退回修改时间 |
| `target_extensions` | 限定扩展名；`[]` = 文档+图片+临时全参与 |
| `create_backup` | 删除前先复制到 `backup_dir` |
| `use_recycle_bin` | 移入 Windows 回收站（强烈建议 true） |
| `auto_clean.*` | 内置定时：开关 / 时间 / 开机自启 |

## 5. 过期判定规则

1. 扩展名不在允许范围 → 跳过（代码/配置/程序文件永远不删）
2. 开 `use_filename_date` 且文件名含日期（`2024-01-15`、`20240115`、`2024年1月15日` 等）→ 按该日期算年龄
3. 否则按文件最后修改时间算年龄
4. 年龄 > `max_age_days` → 过期，先备份 → 移入回收站

## 6. 数据与日志

- 删除报告：`reports\cleaning_report_YYYYMMDD_HHMMSS.json`（每次实际清理生成）
- 删除前备份：`backups\`（勾选 create_backup 时）
- 回收站：所有删除均可从回收站恢复

## 7. 卸载

安装版：设置 → 应用 → 智能文档清理器 → 卸载（会清理注册表自启项）。
绿色版：删除整个 `dist\SmartFileCleaner\` 目录；若勾过自启，到注册表 `HKCU\...\CurrentVersion\Run` 删 `SmartFileCleaner` 项。
